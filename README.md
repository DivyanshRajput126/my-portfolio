# 🚀 Interactive AI Engineer Portfolio

A modern and interactive personal portfolio built with **ReactJS and Three.js** to showcase my **AI/ML projects, technical skills, professional experience, education, and achievements**.

The portfolio combines a responsive React-based interface with **interactive 3D visuals, animations, and smooth transitions** powered by Three.js. Portfolio content, including projects and skills, is managed through **JSON-based data**, making the website modular, maintainable, and easy to update.

## 🛠️ Technologies Used

* **ReactJS** – Component-based frontend development
* **Three.js** – Interactive 3D graphics and animations
* **JavaScript** – Application logic and interactions
* **HTML5 & CSS3** – Responsive UI and styling
* **JSON** – Dynamic portfolio and project data

## ✨ Key Features

* **Interactive 3D Visuals** – Engaging 3D models, animations, and visual effects using Three.js.
* **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
* **AI/ML Project Showcase** – Highlights projects across Generative AI, NLP, Deep Learning, Computer Vision, and Machine Learning.
* **Dynamic Content** – Portfolio information is managed through JSON-based data.
* **Project Demonstrations** – Includes GitHub repositories, live applications, and project demos.
* **Smooth Navigation** – Interactive transitions and intuitive navigation throughout the website.
* **Reusable Components** – Modular React components designed for maintainability and scalability.
